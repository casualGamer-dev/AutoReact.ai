# Surface brief: AutoLayout.ai app (Operate, Android)

Scope: whole app visual identity replacement; behavior, detection, API, navigation untouched.
Audience: devs/students prototyping from paper sketches, offline, one-handed.

## Direction contract

THESIS: Review is proofreading: a machine sets a first proof, the user marks corrections, it is typeset into code. Refuses pastel-green pill utility app.
OWN-WORLD: Cool proof-white ground, ink near-black, blue pencil only for tappable actions, red pencil only for correct/delete, five element classes as five marks (symbol + color), tiny mono slug labels, dark ink clean-proof code screen with pencil/highlighter syntax hues, System-code font as mono voice.
STORY: User sees their own drawing marked up, fixes marks via a labelled tray, confirms, and the marks resolve into code they copy.
FIRST VIEWPORT: Review screen: photo full-bleed, hairline boxes with margin flags (mono abbrev + symbol), slug line "7 marks - 2 corrected", pinned instructions, one blue-pencil "Looks good" at bottom; tap box opens bottom tray of five 48dp mark chips.
FORM: Proofreader's marks on a typeset galley, candidate 4 of 7, seed 210666b6, code-led.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
